DQL · SELECT

SELECT — escolher colunas

SELECT nome, cidade
FROM   cliente;

SELECT * traz todas as colunas; nomeando as colunas você traz só o que precisa (mais claro e mais rápido).

DQL · WHERE

WHERE — filtrar linhas

SELECT nome, cidade
FROM   cliente
WHERE  cidade = 'SP';

Operadores: = <> > < BETWEEN IN (...) LIKE 'A%' IS NULL — combinados com AND / OR.

DQL · ORDER BY

ORDER BY — ordenar o resultado

SELECT id, valor
FROM   pedido
ORDER BY valor DESC;   -- ASC é o padrão

Pode ordenar por várias colunas: ORDER BY cidade ASC, valor DESC.

DQL

LIMIT e DISTINCT

LIMIT — só as primeiras N linhas 
SELECT nome, valor
FROM   pedido
ORDER BY valor DESC
LIMIT 3;
"os 3 maiores pedidos"
DISTINCT — valores sem repetição 
SELECT DISTINCT cidade
FROM   cliente;
-- SP, RJ, MG  (SP aparece 1 vez)

DQL · GROUP BY

GROUP BY — resumir por categoria

Junta as linhas que têm o mesmo valor numa coluna e aplica a agregação em cada grupo.

DQL · GROUP BY

Uma linha por grupo

SELECT status,
       COUNT(*)   AS qtd,
       SUM(valor) AS total
FROM   pedido
GROUP BY status;

Regra: toda coluna do SELECT que não é agregação precisa estar no GROUP BY.

DQL · HAVING

WHERE × HAVING

SELECT status, SUM(valor) AS total
FROM   pedido
GROUP BY status
HAVING SUM(valor) > 500;     -- só o grupo 'pago' (1000)
DQL · JOIN

Os dados estão em duas tabelas

O nome do cliente está em cliente. O valor do pedido está em pedido. A pergunta "quanto a Ana gastou?" precisa das duas.

A ligação: pedido.id_cliente = cliente.id.

DQL · JOIN

INNER JOIN — casar as linhas

DQL · JOIN

INNER JOIN na prática

SELECT c.nome, p.id AS id_pedido, p.valor
FROM   cliente c
INNER JOIN pedido p ON p.id_cliente = c.id
ORDER BY c.nome;

DQL · JOIN

LEFT JOIN — manter todos da esquerda

SELECT c.nome, p.id AS id_pedido, p.valor
FROM   cliente c
LEFT JOIN pedido p ON p.id_cliente = c.id;

Traz todos os clientes. Quem não tem pedido aparece com NULL nas colunas de pedido.

O objetivo

Total gasto por cliente

SELECT c.nome,
       COUNT(p.id)              AS pedidos,
       COALESCE(SUM(p.valor),0) AS total
FROM   cliente c
LEFT JOIN pedido p ON p.id_cliente = c.id
GROUP BY c.nome
ORDER BY total DESC;

LEFT JOIN para não perder o Davi; COALESCE troca o NULL da soma por 0.

Como o banco lê

A ordem lógica das cláusulas

Você escreve começando por SELECT, mas o banco executa nessa ordem — por isso o WHERE não enxerga apelidos do SELECT.
