Visão geral

SQL não é uma coisa só

É uma linguagem única, mas os comandos se agrupam por propósito:

Hoje: DDL (mexe na estrutura) e DML (mexe nos dados) + TCL.
DDL

DDL — a estrutura do banco

Mexe em tabelas, colunas, constraints e índices — não nos dados.

CREATE
cria tabela, índice, schema... (Aula 04)
ALTER
muda uma tabela que já existe
DROP
apaga o objeto inteiro
TRUNCATE
esvazia a tabela (rápido)
DDL · ALTER

ALTER TABLE — mudar sem recriar

-- adicionar coluna
ALTER TABLE aluno ADD COLUMN ativo BOOLEAN DEFAULT TRUE;

-- remover coluna
ALTER TABLE aluno DROP COLUMN telefone;

-- renomear coluna
ALTER TABLE aluno RENAME COLUMN nome TO nome_completo;

-- adicionar constraint
ALTER TABLE aluno ADD CONSTRAINT chk_idade CHECK (idade >= 16);
DDL · DROP

DROP TABLE — apaga o objeto inteiro

DROP TABLE aluno;

-- não dá erro se a tabela não existir
DROP TABLE IF EXISTS aluno;

-- derruba também o que depende dela (FKs)
DROP TABLE curso CASCADE;

DROP tira a tabela e os dados. DELETE tira só as linhas.

DML

DML — os dados dentro das tabelas

Os três aceitam WHERE para escolher quais linhas — menos o INSERT.
DML · INSERT

INSERT — recapitulando

-- sempre liste as colunas
INSERT INTO aluno (nome, email, idade)
VALUES ('Ana', 'ana@ex.com', 19);

-- várias linhas de uma vez
INSERT INTO curso (nome) VALUES
  ('Eng. de Software'), ('Medicina'), ('Direito');

-- deixar o DEFAULT / SERIAL agir: só não informe a coluna
INSERT INTO aluno (nome, email) VALUES ('Beto', 'beto@ex.com');
Detalhes na Aula 04. Aqui o foco é UPDATE e DELETE.
DML · UPDATE

Anatomia do UPDATE

DML · UPDATE

O WHERE esquecido

Sem WHERE, o UPDATE vale para todas as linhas da tabela.

-- QUERIA: só o aluno 3
UPDATE aluno SET idade = 20;   -- ⚠ sem WHERE!
-- resultado: TODOS os alunos ficam com idade 20

O mesmo vale para o DELETE. Antes de rodar, teste o filtro num SELECT ou use uma transação.

DML · UPDATE

UPDATE a partir de outra tabela

Dá para atualizar uma tabela usando valores de outra, com FROM:

UPDATE produto p
SET    preco = preco * 1.10
FROM   reajuste r
WHERE  r.id_prod = p.id_prod
  AND  r.categoria = 'eletronico';

"aumenta 10% no preço dos produtos que estão na tabela de reajuste".

DML · DELETE

DELETE — remover linhas

-- remove linhas específicas
DELETE FROM aluno WHERE id = 3;

-- remove por condição
DELETE FROM pedido WHERE status = 'CANCELADO'
  AND data < '2023-01-01';

-- SEM where = apaga a tabela inteira ⚠
DELETE FROM aluno;
TCL

Transação — tudo ou nada

Vários comandos agrupados: COMMIT confirma todos, ROLLBACK desfaz todos.

BEGIN;
  UPDATE conta SET saldo = saldo - 100 WHERE id = 1;
  UPDATE conta SET saldo = saldo + 100 WHERE id = 2;
-- conferiu? deu certo?
COMMIT;      -- ou ROLLBACK; para cancelar

Ótimo para testar um UPDATE/DELETE arriscado com segurança.
