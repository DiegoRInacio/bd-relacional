# Banco de Dados Relacional

Portal da disciplina de **Banco de Dados Relacional** — Curso de Engenharia de Software,
Universidade de Vassouras. Prof. Me. Diego Ramos Inácio.

🔗 **Site:** https://diegorinacio.github.io/bd-relacional/

## Conteúdo

| Pasta / arquivo | Descrição |
|---|---|
| `index.html` | Portal com as 11 aulas, material de apoio e simulados |
| `Aula_01.html` … `Aula_11.html` | Slides das aulas (HTML, navegáveis com ← →) |
| `apoio/` | Material de referência (SQL, normalização, triggers/views/usuários) |
| `simulados/` | Simulado P1 interativo (motor SQL no navegador) |
| `codigos/` | Scripts SQL usados em aula |
| `assets/` | CSS, imagens e JavaScript do site |

## Aulas

1. O que é um SGBD Relacional
2. PostgreSQL
3. Projeto de Banco de Dados (modelo ER)
4. `CREATE TABLE` e constraints
5. Normalização (1FN, 2FN, 3FN)
6. SQL — DDL e DML
7. SQL — DQL (consultas, JOIN, agregação)
8. Triggers
9. Views
10. Usuários e permissões
11. API RESTful vs. SQL direto no código
